## 一、P0 存在不能忽略的力学矛盾

你提交的 r45 `lift_hold` 数据为：

| 物理量 | 数值 |
|---|---:|
| 双板竖直摩擦力 | +9.603 N |
| 箱体重力 | −3.928 N |
| 桌面支撑 | 0 N |
| 挡杆、角铁 | 0 N |
| 箱体竖直加速度 | 约 0 |
| 报告的残差 | +0.0036 N |

按牛顿第二定律：

\[
ma_z=F_{\mathrm{plates},z}+F_{\mathrm{other},z}-mg
\]

如果其他外力确实为零，那么：

\[
ma_z=9.603-3.928=5.675\ \mathrm N
\]

对应：

\[
a_z=\frac{5.675}{0.4004}\approx14.17\ \mathrm{m/s^2}
\]

这与稳定保持阶段近似静止的箱体矛盾。

**9.603 N 可以是双板实际向上施加的接触力，但不能在没有其他向下作用力的情况下，被解释为对 3.928 N 箱体的静态独立承重平衡。**

因此至少有一种情况需要解释：存在未列出的其他接触力；力的坐标转换或符号处理有误；或者表中不同数值并非同一物理量和同一统计口径。

这不是小数精度问题，而是约 5.675 N 的平衡缺口，达到箱体重力的 144.5%。

### 为什么原验证器没有阻止这个问题？

我在公开源码中确认，`lift_force_account.py` 将接触力归入 `plate`、`table`、`yaw_stop`、`vise` 和 `other`，但打印的分项表并没有单独显示 `other`。与此同时，总力及残差计算会包括 `other`。<Cite refs={["turn491345view1","turn483090view1"]}/>

这意味着可能出现：

- 表中显示双板 +9.603 N；
- 桌面、挡杆、角铁全部为零；
- 未显示的 `other` 接触贡献约 −5.675 N；
- 总残差仍然接近零。

如果存在这种情况，验证器就可能误把“没有指定辅助约束承重”判断为“没有任何其他物体参与承重”。

**这正好触及本轮最重要的科学问题：箱体究竟由哪些接触对支撑，以及哪些接触对施加了反向作用力。**

所以我的 P0 裁决是 **FAIL — ACCOUNT INCOMPLETE**，而不是否定实际起升现象。

### P1：挡杆消融的结论可以保留，但需限定

r44→r45 是有价值的因果干预。箱体解除挡杆、角铁后仍然上升到 7.814 mm，证明了**这些被移除的辅助几何约束不是起升的必要条件**。

但这不自动证明起升时只存在双掌板与箱体的接触。需要列出每帧参与箱体受力的全部 geom，特别是可能被分类为 `other` 的指链、掌部其他碰撞体和未命名接触面。

如果约 −5.675 N 的差额来自手指等机器人自身部件，那么“双掌板独立承重”仍然不成立，但可以改写为“机器人多接触联合承重”。如果来自坐标系错误，则需要修复计算，再判断是否能恢复独立双板结论。

### P3：复现性提升明显，但仍有漏洞

公开验证器已经具备资产哈希核对、失败返回码检查、产物新鲜度检查及 421 帧位置轨迹对比，这是值得加分的改进。

不过还有四项需要修正：

1. **资产异常未完全 fail-closed。** 校验代码在检查缺失文件之前就读取哈希，遇到缺失文件可能直接抛异常；发现哈希不匹配后也没有立即停止运行。应先检查存在，再比较哈希，失败立即退出。
2. **并非所有运行都严格检查返回码。** P2 两次角点复跑将返回码纳入断言，但最终证据轨迹对比前的 `_pipeline(RECIPE)` 没有检查返回码或产物新鲜度。
3. **位置一致不等于完整物理状态一致。** 当前逐帧对比的是箱体三个平移坐标，没有覆盖姿态、速度、接触集合、逐接触力及关节轨迹。
4. **“位级一致”与容差断言不是同一回事。** `max |dpos| < 1e-6 m` 只能保证微米级容差内一致。实测 0.0 是更强的观测结果，但验证器允许非零偏差通过，因此不能把验证契约称为严格位级一致。

另外，P0 原脚本虽能计算逐帧残差，但验证器实际判断的是阶段平均残差，不是每帧最大残差。阶段平均接近零不能排除正负误差互相抵消。

这些不需要重新设计仿真系统，只需要补齐验证器的断言与输出范围。

## 三、r169 双段进入路径：批准作为 v13 起点

**裁决：APPROVE — CONTROLLED BASELINE。**

我同意将 Z=30 mm 的双段进入路径作为 v13 的候选基线，而不是要求退回此前的直进路径。

支持理由明确：根据本次提供的 A/B 数据，抓握前位移从 6.32 mm 降至 4.73 mm，改善约 25%；指链顶箱的已知机制得到缓解；关节限位门由红转绿，而且没有通过修改限位或降低验收标准取得通过。

但需要严格区分：

- Z=30 是**实测有效工作点**，尚不能称为经过完整敏感性分析的最优路径。
- Z=20 失败说明逆运动学分支敏感性仍然存在，不能预设 Z=30 附近存在平滑、连续的可行区域。
- 右腕 30.2%、左腕 19.6% 的保真误差依旧不合格。

### v13 应当怎样修改轨迹？

允许将轨迹优化从单一末端接触目标，调整为多目标约束：

\[
\min_{\mathbf q(t)}\left(
E_{\mathrm{wrist}}
+\lambda_1E_{\mathrm{collision}}
+\lambda_2E_{\mathrm{pregrasp}}
\right)
\]

这里 \(E_{\mathrm{wrist}}\) 对应原始视频腕部轨迹误差，另外两项分别约束非目标碰撞与抓握前箱体位移。关节限位、物理模型、最终真实接触与 10% 保真门继续作为硬约束，不由这些权重替代。

尤其要保留两个固定对照：旧直进路径与 r169 Z=30 路径。否则 v13 的成功可能来自接触条件变化，而无法归因于路径改造。

## 四、剩余约 3 mm 滑移：如何定性？

我的裁决是：

**目前属于“已观测到、尚未判定可接受的抓握建立期位移”，不是独立承重失败的直接证据，但也不能称为已经证明的正常连续平衡滑移。**

首先，必须区分两个问题。

**问题 A：箱体被成功夹持并起升后，是否发生相对掌板滑落？**

如果整个离桌保持阶段，箱体相对双板的位姿稳定，没有持续向下滑移，那么可以判定为起升保持成功。不能把抓握建立期的所有位置变化都视为失抓。

**问题 B：抓握建立之前，箱体是否被不必要地推离原位置？**

这属于任务质量问题。即使后续起升成功，3 mm 的水平位移仍可能构成复刻偏差或接触建立缺陷。

前者说明箱体是否被推走；后者说明夹持是否真正稳定。
