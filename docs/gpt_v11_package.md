## 0. v10 的指定任务 → 本轮回答（先给结论）

v10 指定主任务：**证明单指垫真实接触下，机器人能否依靠摩擦稳定抬起箱体**，并给了
7 条验收。本轮的回答是两句话：

1. **单指垫路线：回答为否，且给出机理与逐帧证据**（§2）。左手指垫的压紧力来自
   0.04–0.18 N·m 的手指伺服：静置时可维持 2.03 N（≥ 1.0907 N 地板），但手一旦竖直
   上移，垫接触点沿面滑动、指角变化、法向力崩塌 —— 实测起升中左垫接触断续
   （多数帧缺失、有力时 0.51 N），箱升 1.53 mm 即滑回 0.10 mm（r149，逐帧账目）。
   推进终端让臂直接顶垫也不行：指链屈曲，squeeze 0.7→1.5 mm 时左力
   2.035 → 0.07/0.28/0.48 N 崩塌，而同期右板 4.16 → 9.94 N 单调上升。
2. **在 v10 授权 B（掌板/拇指对握独立设计分支）内，双手掌板起升成立**：双侧掌板
   真实接触（陷深 −0.0495/−0.0486 mm，端面矩形内）、法向力 22.2401/22.5573 N、
   箱体竖直上升 **6.0798 mm** 并保持（峰=终）、**桌面支撑力从 3.928 N（全重）
   降为恰 0**、无滑移回落、净室克隆两次全新运行逐位一致。7 条验收逐条见 §3。

这不是把"单垫不可能"说成结构性定论 —— §4 给出结论的适用域边界。

## 4. 结论的适用域（对 −0.30 的正面回应）

本轮所有"不可行"表述的精确形式：

- "单指垫起升不成立" ≡ 在本场景的 Allegro 手指伺服（0.04–0.18 N·m）、μ=1.8、
  0.4004 kg、6 mm/90 帧竖直起升条件下，实测力崩塌。**未主张**：任何更硬手指伺服、
  更低摩擦需求或更慢起升下也不成立。
- "双垫同时贴面不可达" ≡ 三次搜索（r119 记录）在已测参数域零命中。v10 已指出
  有限样本零命中 ≠ 全局不可达 —— 接受，不再以结构性定论措辞。
- "双垫贴面不是单垫起升的必要条件" —— v10 正确；本轮实际执行的单垫起升失败
  机理（§2）与贴面判据无关，是力维持问题。

## 6. 验收门语义与本轮判据适用域（需评审知悉）

- `gate6_executed_contact`（真实接触 + 力地板）为本轮接触判据，双侧 PASS。
- `gate1_final_touch` 仍红：其判据是**垫片矩形**（每手 ≥2 垫在面中带内）。在授权 B
  的板分支下按构造不可能满足（右臂 0 垫入矩形，rect_dist 46.92 mm）。板分支的
  等价判据即 gate6。**这是判据适用域问题，不是新增物理失败** —— 是否为板分支
  定义对应的门，提请评审裁决。
- `gate4_joint_limits` 仍红：仅因左手指 qpos 越界 **8.085628e-07 rad**（第 172–207
  帧中 15 帧），判据为严格 `==0.0`。未放宽阈值，如实留红。
- `gate5_palm_deviation` 红：左终端换成板位姿后的掌偏差，授权 B 设计变更的
  直接结果，非执行失败。

  重注册（原 ego 视角吊顶路径在侧装单元物理不可行：r53 实测左拇指 228 接触帧、
  箱被推 55 mm）与 `W6B_R23_FLYOVER_MM=250` 的钟形抬升。本地 A/B 证实帕累托

  拇指贴桌 29 帧。**10% 保真限与零手-桌接触在侧装单元当前不可兼得** ——
  真回贴需把接近段改为视频路径在可达无碰撞走廊内的投影，属下一轮独立设计
  任务，阈值重定义提请评审裁决而非自行放宽。

## 8. 仍然红 / 欠账（按实报）

2. **起升工作点的夹紧力为 22 N 级，不是"温和双压"**。温和双压（≤3 N、箱移 <1 mm）
   被证明是路径规划问题：左插入途中张开的手指链扫掠切箱 12.2 mm

   对面板楔死。已排除：BLEND_SECONDS（1.6/4.8/9.6 逐位惰性）、双侧终端 trim
   （力响应 bang-bang：左 20 N 或 0，窗宽 ≈2 µm）、staging（双稳 17–49 N）、
   两相插入（非执行写入者）、右 curl 延迟（无效）。**起升改在 22 N 下直接达成**，
   但若评审要求温和夹紧，需重开左插入路径规划（两相：远处旋转、贴面平移）。
3. 力对几何扰动的系统扫描欠账（−0.25 的余项）：现有数据点：squeeze 0.2→2.0 mm
   单调 1.42→12.42 N；陷深工作点 −0.0495 mm 位于窗中部。未做扰动包络。
4. **v6/v7 ceiling cell 与 w6c 的克隆级复验未做**（−0.15 余项）。
5. 接近段箱体横移 4–5 mm（抓握前瞬态，滑入 yaw 挡杆后楔住）——起升不受阻
   （摩擦裕度 20×），但"抓握前箱被动位移"如实披露。
6. 旁载接触：yaw_stop_negy 1.00 N、r22 vise 角铁 0.67 N（−0.013 mm）。
