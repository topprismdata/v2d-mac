## 二、六个争议逐项裁决

### 1. gate1 是不是改判据换来的？

**结论：原 legacy gate1 的 PASS 可以认可，但不认可 v2 被证明“不可能满足”的完整论证。**

弯曲量、贴面目标和二维搜索改变的是控制目标及运动学解，不是直接放宽 gate1 的数值阈值。因此不能简单认定为刷分。

但存在一个明确的数学矛盾：

报告给出的共面跨度是右 0.12mm、左 0.31mm，而 R5 公差为 0.116mm。

- 如果 R5 表示每个相关垫对中心面的最大绝对偏差，0.31mm 的全跨度在最优居中后至少留下 0.155mm 的最大偏差，超过 0.116mm。
- 如果 R5 只是选定两个有效垫的距离，则全组三指的跨度可以超过阈值，但必须明确哪些垫进入验收集合。

另外，`pad_center_buried_v2` 若按整个包含拇指的垫集合进行验收，确实与三指侧面抓握的任务语义不匹配。但正确做法不是永久保留互相矛盾的两个埋入标志。

建议冻结历史 gate1，同时发布一个语义明确的新判据：

`eligible_contact_pads` 定义参与抓握的垫子集合；拇指只有承担该侧面接触角色时才纳入。对集合逐垫检查面内位置、表面间隙和接触证据。

**裁决：legacy gate1 PASS；v2 的替代方案尚未完成。**

### 2. 执行态 4.39/4.59mm 是否等于接触？

**结论：不等于。应该以垫表面到盒表面的有符号间隙及求解器接触结果为主指标。**

假设垫是半径 6mm 的圆柱，圆柱轴平行于盒面，且最近表面位于垫心与盒面法向之间：

\[
g=d_{\text{center}}-r
\]

则 4.39mm 和 4.59mm 分别意味着名义穿入 1.61mm、1.41mm，而不是 0.2mm 的正间隙。

实际还取决于圆柱方向、端帽、倾角、碰撞几何和 MuJoCo 接触求解结果。仅凭垫心距不能计算真实表面间隙。

应该同时输出三个字段：

| 指标 | 用途 |
|---|---|
| `pad_center_to_face_mm` | 几何定位与历史对照 |
| `pad_surface_signed_gap_mm` | 真实表面距离，负值表示几何重叠 |
| `contact_normal_force_N` | 是否实际产生法向接触作用 |

建议同时记录接触持续帧数与相对滑移。仅有零间隙而无法形成有效接触力，也不代表可靠抓握。

**裁决：执行态 5mm 中心距离门可按现行口径通过；真实接触尚未获证。**

### 3. 拇指离面 107mm，却参与前向轴计算，是否错误？

**结论：是，作为目标抓握方向的测量代理存在语义错误。**

四垫中心并不是天然正确的末端接近方向。当拇指被设计在另一侧或承担对掌作用时，把它和三根工作指混合求质心，会让“接近方向”受到手指张合和重力下垂的显著干扰。

建议分成：

- `palm_forward_axis`：由掌部刚体坐标系定义。
- `grasp_contact_normal`：由有效接触垫的法线及目标盒面定义。
- `all_pad_centroid_axis`：保留为历史诊断字段，不再作为唯一的物理接近角。

原先的 35° 门应保留用于历史可比性，但新物理判据必须另立版本，不得直接把新结果混报成旧门改善。

### 4. gate3 分开报告接近段碰桌与终端窗干净，算不算选择性窄化？

**结论：分开报告本身正确，但本次“终端窗干净”还存在需要澄清的矛盾。**

文档一方面报告每侧有 1 帧接触位于 gated terminal window，另一方面称 terminal window clean。<Cite ref="turn500502view0"/>

如果这 1 帧是受禁止的手桌接触，并且位于正式判定窗口内，那么“窗口全净”不能成立。只有当它属于允许接触，或者和正式评分窗口的定义不同，才能同时成立。

必须将两件事分开：

`gate3_full_trajectory = FAIL` 可以与 `gate3_terminal_only = PASS` 同时成立，但终端窗内禁止接触不得超过原判据允许的上限。

我认可你这次双侧、分部件、分窗口的取证改进，明显好于 v6 选择性只报一侧。

**裁决：审计方式 PASS；窗口无违规声明 PENDING。**

### 5. 盒子从 0.15kg 改为 0.4kg，是否通过物理参数换指标？

**结论：构成明确的性能相关参数干预；不能称为作弊，但不能作为未经限定的真实复刻成绩。**

质量提高约 2.67 倍。在相同施力条件下，它改变物体的加速度和惯性响应。你们又明确知道较轻盒子会滑动 16.7mm，增重则用于压低执行态偏差，因此这不是无关紧要的场景设置。

尤其前一版曾发生 955N 毒链，当前必须对力的来源保持敏感。不能为了获得贴面距离改善，就让夹持反作用力通过质量或摩擦参数被掩盖。

建议将 0.4kg 标为 `simulation_reference_mass`，并以相同控制器跨质量运行敏感性实验。至少覆盖 0.15、0.25、0.4kg，并报告盒体位移、接触力、执行态距离和是否滑移。

**裁决：0.4kg 的仿真结果有效；对真实未知质量的传输性未证明。**

### 6. 右手指离面矩形 14mm，仍然 gate1 PASS？

**结论：按原 ≥2 垫的规则可以 PASS，但它确实不是完整四指贴合。**

不建议事后把旧判据改成必须四指贴合。这样会破坏整个战役的可比性，也可能脱离人类原片的实际抓握模式。

但现在需要区分两个对象：

- `gate1_legacy`：至少两垫满足位置与角度条件，允许通过。
- `grasp_quality`：实际接触垫数、位置分布、法向、受力与支撑能力。

尤其不能用两个相邻垫都在面内，替代对抗滑移和旋转的接触稳定性分析。

**裁决：规则通过成立；四指抓握质量不成立。**
