# v6 终审裁决：8.9/10（v5：8.4 → v6：+0.5）

**结论：APPROVE with scope limitations。认可 v6 作为可传输证据链交付版；不认可其作为抬离成功版，也不认可将基础环境的失败升级为全局力学不可能性证明。**

本轮最大的进步不是指标改善，而是推翻了错误因果链、撤销不可复现的正结果，并让保留的两项主张通过独立重建验证。

以下依据评审包所述证据作裁决，尚不等同于我独立运行 verifier 后的认证。

## ① 传输性验证：认可新定位

**PASS，且这是 v6 最有价值的增量。**

三条头条的最终状态：

| 主张 | 裁决 | 证据地位 |
|---|---|---|
| 43.46mm 举升 | REFUTED | 正结果撤回，不得引用为成功案例 |
| 诚实 vise：9.72/6.53N | VERIFIED（报告级） | 帧 0 静态解成立，不外推为稳定动态抓取 |
| r26 R5 双侧精度 | VERIFIED（报告级） | 全精度重放成立，不外推为全门通过 |

我认可“**2 条三轮 VERIFIED + 1 条诚实撤回**”的交付定位。

但需要明确区分两种验证：

- **传输性**：从公开配方、干净初始化与指定依赖重建结果。
- **独立正确性**：验证模型物理语义、判据实现和参考答案本身是否正确。

三轮相同结果证明了可重复性，并不自动证明物理模型没有系统性偏差。尤其 r26 的微米级 pad1 距离只能证明当前接触几何与计量实现中的确定性。

**裁决：证据工程显著超过 v5；物理任务成功仍未建立。**

## ② 34/96 策略中断：负结果有效，因果结论须降级

**PARTIAL PASS。**

34/96 iterations 不是“部分收敛”的充分证据。迭代比例不能替代学习曲线、策略稳定性或收敛诊断。

因此：

| 声明 | 裁决 |
|---|---|
| 当前训练出的策略 0/3 seed 举升失败 | 成立 |
| 32/32 网格在给定搜索域内失败 | 成立 |
| 两种方法均受到当前接触几何限制 | 有力支持 |
| 44-DoF 动作空间结构性不可举升 | 尚未证明 |
| 继续奖励塑形必然无效 | 证据不足 |

网格搜索与 MLP 策略共享同一环境、执行器和接触几何，不构成对结构性不可行的完全独立验证。

尤其 `peak −0.57..−0.62mm`，它说明测试中没有跨过举升门槛，不等于证明所有可达控制轨迹都不可能跨过。

建议把正式结论改为：

**“在已检验控制策略、搜索域及物理配置内，未发现可重复的抬离轨迹；存在明确的接触可达性阻塞证据。”**

不得写成“已经证明 RL 无法解决”。

## ③ C-STABILITY：认可当前失败终态，不认可全局封死

**当前配置 NO-LIFT：PASS。全系统不可举升：NOT PROVEN。**

955N 毒链是关键发现。它意味着旧版 N 值、摩擦边界推断、历史 checkpoint 及其派生实验均不能继续作为独立证据使用。

重座位终票提供了两条可信的失败证据：

- `N-curl=0`：当前卷曲配置没有形成目标垫接触。
- settle 抛盒 414mm：该变体不能维持有效的初始抓取状态。

但这两项失败属于不同环节：前者是接触可达性，后者是初始状态稳定性。不能将它们合并成 MuJoCo 求解器不可行证书。

我只保留三条有意义的后续线索：

1. **可达性证明**：在固定手指几何、关节限位、碰撞约束和允许控制空间下，求解离面垫的最大可接近深度，并给出数值上界。
2. **接触模式搜索**：不要只扫描腕位姿。729 单元空集未覆盖手指关节自由度；需要在允许手指构型内检查可行接触模式。
3. **准静态路径证书**：从 verified vise 出发，搜索连续、无穿透、满足力矩与摩擦约束的正向抬升路径。若连局部连续路径都不存在，才有更强的结构性阻塞证据。

这不是要求继续无边界地调参。

**封卷当前 C-STABILITY 失败结果，允许另立“可行性证明”研究任务；不允许再用当前失败去声称求解器边界。**

## ④ f150 / 楔形机制：整体冻结正确，但需要分层

**冻结 43mm 举升及其因果解释是正确的；把所有独立观测一起作废则过度。**

| 证据层 | 应有状态 |
|---|---|
| 原 session 的 +27° 垫倾角 | HISTORICAL OBSERVATION，未传输 |
| 楔形 pinch-lift 几何原理 | HYPOTHESIS，理论上可检验 |
| +27° 导致 +43mm 举升 | WITHDRAWN |
| 八方案均无法复现 | 只对各自已记录试验成立 |
| “求解器暖启动盆地效应” | WITHDRAWN，缺乏独立证据 |
| 诚实 vise 帧 0 静态 jam | VERIFIED，独立保留 |

关键是不能因为原 session 的正结果被推翻，就推断楔形接触机理在物理上不存在。

同样，也不能因为模型曾记录 +27°，就将其当成当前干净环境可达的有效机制。

最合理的状态是：**观察记录保留、举升因果撤回、机制假说待验证。**
