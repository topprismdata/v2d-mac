# 勘误：v6–v10 各包中"双垫（≥2 垫）贴合"表述的物理含义修正

依据 GPT v10 评审（`docs/gpt_v10_review.md` Q10）的裁决：历史包保持冻结、不得改写，
但必须统一勘误，明确区分三层含义：

1. **命令态几何满足** —— 指垫**中心**落在端面矩形 R5 内（v1/v2 判据所测）；
2. **执行态表面接触成立** —— 求解器注册的真实接触、最近点在端面上、未深陷（v3/gate6）；
3. **执行态具有承载能力** —— 真实接触的法向力合计达到任务需求（gate6 的力地板）。

## 现行判据体系（v10 评审后）

- **gate1 v1/v2**（命令态中心几何）：保留，兼容性诊断；
- **gate1 v3**（表面判据，命令态+执行态并行发布）：保留；
- **gate6_executed_contact**（`retarget/retarget_dual.py`，本勘误同轮加入）：**物理验收硬门** —— 求解器注册的真实端面接触 + 法向力合计 ≥ m·g/(2μ)（场景自带质量与摩擦导出）；
- 执行态零接触 → gate6 红 → verdict fail，无论命令态几何多绿。

## 不受本勘误影响的结论

接近路径与分支连续性（v9 闭合的 generalization_scan 证据）、r26 配方可复现性、
克隆级复验流程均与"双垫"表述无关，不受影响。
