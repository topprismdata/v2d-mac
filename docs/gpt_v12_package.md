1. **轨迹保真仍 FAIL**：右 30.2% / 左 19.6% vs 10% 原门。该指标量测执行腕迹对
   人手视频的复刻（approach 帧 1–151）。本轮 r169 路径改造针对的是碰撞/预位移
   （见下），对保真段无改善，也未声称改善。10% 门原样保留，未提出任何放宽。
2. **r169 双段进入的 A/B**（`W6B_R169_ENTRY_Z_MM_LEFT`）：针对评审 §三.2 的
   机制 B —— 左臂直进进入下中指中节以 1.7→22.4 N 顶箱（r162 力矢量取证）。
   Z=30 航点 + 垂直末段：顶箱消除、抓握前漂移 6.32 → 4.73 mm、升 7.15 mm
   保持、gate4 变绿。Z=20 失败（IK 分支破坏，rise 翻倍）已如实入账 —— 航点
   几何存在分支双峰，Z=30 是实测选定工作点，不是扫出来的巧合（机理：进入段
   指链从面缘上方掠过而非穿越）。
3. **剩余 ~3 mm 落座滑移**：Z=30 下分解为早期 ~1.6 mm（无接触记录，待查）+
   落座挤压段 ~3.1 mm。对 µm 级左右 trim 不敏感（右侧 trim 在此路径未接线，
   已验证逐位无效）。性质从"指链扫面事故"降级为"双板无约束挤压的连续平衡
   滑移" —— 这正是消融显示系统不依赖挡杆的代价，作为 v13 的输入。
4. **历史分支净室回归**：v6/v7 ceiling 与 w6c 的克隆复验仍未补（v10/v11 欠账
   延续），本轮未动历史包。
